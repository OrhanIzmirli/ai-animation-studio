# comic_rooftop_01 — inputs

`comic_rooftop_01` is a generation benchmark: there is no source footage to
edit, so this folder is currently empty.

It may later hold an optional layout or animatic clip (a rough timing and
camera guide for the ~5 second push-in). If one is added, it becomes part of
the fixed benchmark and requires a new definition version
(`comic_rooftop_02`), because runs of `comic_rooftop_01` were made without it.

Media files in this folder are git-ignored; their checksums are recorded in
every run that uses them. Never modify a file after it has been used.
